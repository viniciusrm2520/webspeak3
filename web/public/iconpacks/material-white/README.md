# Material4Teamspeak icons (white)

A subset of the **Material4Teamspeak Icon Pack** by sapphyrus, based on
DarkenTS by @Brady_The, used by the Standard theme for the client status
icons in the channel tree (talk lamp, muted mic/sound, away, channel, server).
